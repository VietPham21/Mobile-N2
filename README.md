## 5. Quy chuẩn đóng góp mã nguồn

### 5.1. Quy tắc đặt tên nhánh

Tất cả các nhánh phát triển phải tuân theo quy tắc đặt tên dưới đây:

| Mục đích | Định dạng | Ví dụ |
|----------|-----------|-------|
| Tính năng mới | `feature/<ten-tinh-nang>` | `feature/dang-nhap` |
| Sửa lỗi | `fix/<mo-ta-loi>` | `fix/loi-hien-thi-avatar` |
| Cải tiến / Tối ưu | `improve/<mo-ta>` | `improve/toi-uu-truy-van` |
| Tài liệu | `docs/<mo-ta>` | `docs/cap-nhat-readme` |
| Hotfix khẩn cấp | `hotfix/<mo-ta>` | `hotfix/crash-khi-dang-nhap` |

**Lưu ý:** Tên nhánh viết thường, không dấu, các từ cách nhau bằng dấu gạch ngang (`-`).

### 5.2. Quy trình tạo Pull Request

**Bước 1 — Tạo nhánh mới từ `main`:**

```bash
git checkout main
git pull origin main
git checkout -b feature/<ten-tinh-nang>
```

**Bước 2 — Phát triển và commit:**

```bash
git add .
git commit -m "feat(<scope>): <mo ta ngan gon>"
```

Quy ước commit message:

| Prefix | Ý nghĩa |
|--------|----------|
| `feat` | Thêm tính năng mới |
| `fix` | Sửa lỗi |
| `docs` | Cập nhật tài liệu |
| `style` | Thay đổi định dạng code (không ảnh hưởng logic) |
| `refactor` | Tái cấu trúc code |
| `test` | Thêm hoặc chỉnh sửa test |
| `chore` | Cấu hình, build, dependency |

**Bước 3 — Push nhánh lên GitHub:**

```bash
git push origin feature/<ten-tinh-nang>
```

**Bước 4 — Tạo Pull Request trên GitHub:**

- Vào repository trên GitHub, chọn **"Compare & pull request"**.
- Điền tiêu đề và mô tả rõ ràng nội dung thay đổi.
- Chọn nhánh đích là `main`.

**Bước 5 — Kiểm tra xung đột và review:**

- Nếu có xung đột (**conflict**), phải xử lý cục bộ trước khi yêu cầu merge:

```bash
git checkout feature/<ten-tinh-nang>
git pull origin main
# Xử lý conflict trong các file được đánh dấu
git add .
git commit -m "fix: xu ly conflict voi main"
git push origin feature/<ten-tinh-nang>
```

- Pull Request cần ít nhất **1 approval** từ thành viên khác trước khi được merge.
- Không tự ý merge khi chưa có review.

**Bước 6 — Merge và dọn dẹp:**

- Sau khi Pull Request được approved, tiến hành merge trên GitHub.
- Xoá nhánh đã merge để giữ repository gọn gàng:

```bash
git branch -d feature/<ten-tinh-nang>
git push origin --delete feature/<ten-tinh-nang>
```
